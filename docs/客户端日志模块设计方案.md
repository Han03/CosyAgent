# CosyAgent 客户端日志模块设计方案

> 版本：v0.1
> 目标：客户端（Flutter，Windows 桌面 + 移动端）运行时问题可留痕、可定位。
> 触发背景：设置页"测试连接"曾出现 `DioException [unknown]` 但服务端健康——请求层异常需文件日志支撑排查。

## 1. 目标与边界

| 目标 | 说明 |
| ---- | ---- |
| 留痕 | 每次 HTTP 请求/响应/错误、全局未捕获异常、关键配置事件写入本地日志文件 |
| 可定位 | 日志含时间、级别、来源模块、上下文（会话/任务/URL），支持事后回溯 |
| 低侵入 | 不改变现有业务代码结构，仅新增 core/logging 模块 + 在既有入口埋点 |
| 跨端 | Windows 桌面与移动端统一 API，日志目录按平台解析 |

边界：日志为**排查辅助**，不承担监控告警；不记录敏感明文（API Key 脱敏）；不做网络上报。

## 2. 日志分级与格式

级别：`DEBUG < INFO < WARN < ERROR`（默认 INFO，DEBUG 经 `--dart-define=COSY_LOG_LEVEL=debug` 开启）。

单行格式（管道分隔，空格对齐）：

```
2026-09-24 07:47:12.345 INFO  [http]  POST /api/agent/chat -> 200 OK (128ms)
2026-09-24 07:47:12.512 ERROR [app ]  未捕获异常: DioException[unknown] (null)
```

- 时间：本地时区毫秒级
- 级别：5 字符定宽
- 模块 tag：5 字符定宽（http / app / cfg / mock / sys）
- 内容：单行优先；异常多行时后续行以 `  ` 缩进，保证首行可 grep

## 3. 存储策略（文件持久化）

| 项 | 策略 |
| --- | ---- |
| 日志目录 | Windows：`%APPDATA%\com.cosy\cosy_agent_app\logs\`（path_provider 的 application support 目录，与 flutter_secure_storage 同根）<br>移动端：应用文档目录 `.../logs/` |
| 文件命名 | `cosy-YYYYMMDD.log`（按天一个文件） |
| 轮转 | 单文件超 5 MB 时滚动为 `cosy-YYYYMMDD-<seq>.log`（seq=1,2,…） |
| 保留 | 启动时清理 7 天前的日志文件 |
| 写入 | 同步追加（`File.writeAsString(mode: append)` 走事件循环，量小无阻塞风险）；并发写入经单一 Logger 串行化 |
| 异常落盘 | 写入失败降级为 debugPrint，不抛错影响主流程 |

## 4. 模块设计

```
lib/core/logging/
├── cosy_logger.dart     # 门面：Logger.debug/info/warn/error，级别过滤，tag 定宽
└── log_file.dart        # 文件通道：目录解析、按日命名、大小滚动、过期清理
```

- `CosyLogger`：进程级单例（`CosyLogger.instance`），持 `LogFile` + 当前级别；线程安全由 Dart 单线程事件循环保证。
- `LogFile`：构造时解析平台目录（`path_provider`），提供 `append(line)` 与 `init()`（建目录、清理旧文件）。
- 调试镜像：`kDebugMode` 下同行走 `debugPrint`，release 仅写文件（避免控制台开销）。

## 5. 接入点（埋点清单）

| 接入点 | 位置 | 事件 |
| ----- | ---- | ---- |
| 应用启动 | `main.dart` | 版本、内置 BaseURL、Mock 默认、日志目录路径 |
| HTTP 请求 | `api_client.dart` LogInterceptor（改造） | 请求：方法 + 路径 + headers 摘要（Key 脱敏）；响应：状态码 + 耗时；错误：类型 + message + 堆栈 |
| 全局异常 | `main.dart` | `FlutterError.onError` / `PlatformDispatcher.onError` / `runZonedGuarded` 捕获未处理异常与错误 |
| 配置变更 | `settings_page.dart` `_save()` | baseUrl / Mock 开关变更（Key 脱敏） |
| 鉴权事件 | `api_client.dart` `_onUnauthorized` | 401 触发时记录 |

敏感信息规则：API Key 永不落盘；Mock 开关仅记布尔值。

## 6. 依赖

- `path_provider`（Windows/Android/iOS/macOS 均支持，获取应用目录）
- 其余仅用 `dart:io`，无新增运行时依赖

## 7. 验收标准

1. 单测：级别过滤（DEBUG 关闭时不写）、按日文件命名、大小滚动触发、过期清理逻辑
2. `flutter analyze` 零问题
3. `flutter test` 全过
4. Windows release 构建成功、启动进程存活
5. 冒烟：启动后 `logs/cosy-<date>.log` 生成且包含启动横幅与 HTTP 请求行
